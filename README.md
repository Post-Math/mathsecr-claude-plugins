# 수학비서 Claude 플러그인

수학비서 사용자를 위한 Claude Code · Claude Desktop 플러그인입니다. 플러그인을 설치하고 수학비서 계정으로 로그인하면 Claude 에서 수학비서 자료를 찾고 살펴볼 수 있습니다. 사용자 PC 에 따로 설치하거나 설정할 것은 없습니다.

## 할 수 있는 것

| 기능 | 이렇게 물어보세요 |
|---|---|
| 문항 탐색 `/mathsecr:questions` | "공통수학1 이차함수 중상 난이도 문항 찾아줘", "이 문항과 비슷한 문제 보여줘" |
| 나만의 DB `/mathsecr:mydb` | "DB화 끝난 내 DB 목록", "○○ 기출 DB 문항 구성 보여줘" |
| 분석지 `/mathsecr:myanalysis` | "내 분석지 결과 요약해줘", "기준 문항마다 유사문제 몇 개야?" |
| 문제지 `/mathsecr:mypaper` | "○○ 시험지 배점 합계 맞아?", "문제은행에서 바뀐 문항 있어?" |
| 근거 기반 분석 `/mathsecr:analysis` | "문제지 진단해줘", "두 문항 비교해줘", "대체 문항 추천해줘" |
| 연결 확인 `/mathsecr:status` | "수학비서 어느 계정으로 연결돼 있어?", "문제은행 이용 중이야?" |

Claude Code 에서는 여러 번 조회해야 하는 일을 맡는 에이전트도 함께 설치됩니다.

- `question-scout`: 조건에 맞는 문항 후보를 모아 표로 정리합니다.
- `paper-reviewer`: 출제 완료 문제지의 단원·난이도·배점을 점검합니다.
- `math-analyst`: 분석 레시피를 실행하고 저장 데이터와 이미지 해석을 구분해 보고합니다. Chat에서는 analysis 스킬이 같은 일을 직접 합니다.

슬래시 명령을 쓰지 않고 평소처럼 물어봐도 됩니다.

## 설치 (Claude Code)

```
/plugin marketplace add Post-Math/mathsecr-claude-plugins
/plugin install mathsecr@postdemy
```

설치한 뒤 `/mcp` 에서 `plugin:mathsecr:api` 를 골라 **Authenticate** 를 누르면 브라우저에서 수학비서 로그인 화면이 열립니다. 로그인하고 접근을 허용하면 연결이 끝납니다. `/mathsecr:status` 로 연결된 계정을 확인할 수 있습니다.

## 설치 (Claude Desktop)

- **Code 탭**: Claude Code 와 같습니다. 프롬프트 입력창 옆 **+** → 플러그인에서 설치하고 위와 같이 로그인합니다. WSL 세션에서는 플러그인을 쓸 수 없습니다.
- **채팅**: 플러그인을 설치하면 스킬(위 표의 기능)이 들어오고, 수학비서는 **커넥터**로 연결해 로그인합니다. 에이전트는 채팅에서 쓰이지 않습니다.

## 버전 확인

- **설치한 버전:** Claude Code 에서 `/plugin` → 설치됨 목록의 `mathsecr` 항목에 버전이 나옵니다. 새 버전을 받으려면 `/plugin marketplace update postdemy` 를 실행합니다.
- **배포된 버전:** 저장소의 태그·릴리스(`mathsecr--v<버전>`, 예: `mathsecr--v0.4.12`)와 [변경 기록](CHANGELOG.md)에서 확인합니다. 변경 기록의 맨 위가 지금 배포된 버전입니다.

## 할 수 없는 것

지금 제공하는 기능은 **읽기 전용**입니다. 문제지 만들기·문항 담기·배점 설정·출제·학생 배포·채점·서버 분석 실행·구매·파일 내려받기는 수학비서 웹에서 해 주세요. 편집 중인 문제지의 문항 구성도 웹에서 확인할 수 있습니다. 단원·난이도는 저장 정보로 답합니다. "문항 보여줘"는 보기 링크, "읽어줘·비교해줘"는 필요한 이미지 판독으로 이어집니다. 해설 이미지도 분석할 수 있지만 요청 없이 정답을 공개하거나 문항·풀이를 전사하지 않습니다.

서버의 읽기 전용 도구 29개를 사용합니다. 직접 판독은 회원 공용 하루 300장, 요청당 기본 4장(필요한 비교는 8장 이내)으로 제한합니다. 링크는 최대 10문항을 묶으며 한 이미지는 5분·5회, 여러 이미지는 10분·항목당 3회입니다. 권한상 볼 수 없는 부분과 판독 실패는 따로 알려 드립니다.

## 개인정보

- 로그인은 수학비서(mathsecr.com) 계정으로 하며, Claude 에는 수학비서 비밀번호나 로그인 토큰이 전달되지 않습니다.
- 학생 개인정보(이름·답안·점수·명단)는 제공하지 않습니다. 자료 제목 외의 메모·파일명도 Claude 로 보내지 않습니다.
- 자료 제목은 Claude 로 전달되므로 제목에 학생 이름을 넣지 않기를 권합니다.
