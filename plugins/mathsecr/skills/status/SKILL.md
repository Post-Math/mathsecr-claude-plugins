`whoami` 도구를 불러 지금 연결된 수학비서 계정을 확인하고, 결과를 한국어로 한두 문장으로 알려 줘.

- 성공하면: "수학비서에 **{이름}** 님 계정으로 연결돼 있어요." 처럼 이름을 말한다. 회원 ID 는 묻지 않으면 말하지 않는다.
- 문제은행 구독 상태(`problemBankSubscription.status`)도 한 줄로 알린다: `subscribed` → 「문제은행: 이용 중」(종료일 `endDate` 는 물을 때만), `not_subscribed` → 「문제은행: 이용 중 아님」, `unknown` 이거나 필드가 없으면 → 「문제은행 구독 상태는 확인하지 못했어요(연결은 정상)」. 조회 시점 값이다. 구독을 권하지 않고, 확인·변경은 수학비서 웹에서 하도록 안내한다.
- 도구가 없거나 인증이 필요하다는 오류면: Claude Code 에서는 `/mcp` 를 열어 `plugin:mathsecr:api` 서버의 인증(Authenticate)을 진행하라고 안내하고, Claude Desktop 에서는 설정 → 커넥터에서 수학비서를 연결하라고 안내한다.
- "연결이 끊겼습니다" 류 오류면: 수학비서 로그인이 만료됐다는 뜻이니 같은 방법으로 다시 연결하라고 안내한다.
- "output schema" 불일치 오류나, 도구 정의에 있는 입력이 "입력 형식" 오류로 거절되면: 수학비서 서버가 업데이트됐는데 Claude 가 예전 도구 정의를 쓰고 있다는 뜻이다. Claude Code 에서는 `/mcp` 에서 `plugin:mathsecr:api` 를 다시 연결(Reconnect)하거나 새 세션을 열고, Claude Desktop 에서는 새 대화를 열라고 안내한다. 같은 대화에서는 앞서 읽은 예전 도구 정의를 계속 따를 수 있으니, 다시 연결 뒤에도 같은 오류가 나면 새 세션(대화)을 열게 한다. 로그인은 다시 하지 않아도 된다.
