# 단원 자료 한꺼번에 받기 (분포·ID 목록·이미지)

"이 단원 자료를 전부 받고 싶다"는 요청을 처리한다. MCP 에는 일괄 내보내기·다운로드가 없다. 먼저 규모와 비용을 알리고, 분포 → 범위 좁히기 → ID → 이미지 순서로 나눠 준다.

1. **단원 확정.** `chapter_tree` 로 단원을 찾는다. 같은 이름 단원이 여럿이면 `nodePath`·`tree_id` 로 나눠 표로 보여 주고 각각 따로 센다. 별칭 단원(`isAlias`)은 `originTreeId` 를 쓰고 원본 단원이 어디인지 밝힌다.
2. **규모.** `cell_search(limit: 1)` 의 `totalCount` 로 전체 수를 읽는다. 범위(`problemBankScope`)를 밝힌다.
3. **난이도 분포.** `minDifficulty = d`(`maxDifficulty` 없이), `limit: 1` 로 d=1~9 의 `totalCount` 를 읽고, d 칸 = (d 값 − d+1 값), 9 칸 = 9 값. 2번에서 읽은 전체 수 − (`minDifficulty = 1` 값) = 「난이도 없음」(전체 수를 다시 조회하지 않는다). `minDifficulty = maxDifficulty = d` 로 센 수를 더하지 않는다(같은문제 묶음이 두 칸에 들어갈 수 있다). `include` 로 센 수는 구독 상태에 따라 다르다(구독 중이 아니면 보유·공용 문항만). 드문 구간(1~2, 8~9)은 이웃 값의 차로 묶어도 된다(a~b 구간 = a 값 − b+1 값). 한 페이지 결과로 분포를 내지 않는다.
   - 문항 난이도는 소문항마다 회원 값, 없으면 수학비서 값을 쓴 최댓값이다. 난이도 없는 문항은 minDifficulty 를 주면 빠지고 maxDifficulty 만 주면 들어온다. 같은문제 묶음은 묶음 안 가장 높은 값의 칸에 한 번 든다.
4. **하위 단원 분포.** 필요하면 하위(5단계) 단원별로 `limit: 1` 을 불러 센다. 하위 단원이 많으면 상위 몇 개만 세고 나머지는 세지 않았다고 적는다.
5. **비용 안내.** 다음을 먼저 알린다.
   - ID 목록: 한 번에 20개까지라 전체를 받으려면 약 `totalCount / 20` 번 조회해야 한다.
   - 이미지: 직접 판독은 회원 공용 하루 300장이다. 보기 링크는 한 번에 10문항까지 열린다.
   - 전체를 한 파일로 받는 기능은 MCP 에 없다. 필요하면 수학비서 웹을 이용한다.
6. **범위 좁히기.** 고난도만, 특정 하위 유형만, 특정 난이도만처럼 좁힌 범위를 제안하고, 좁힌 범위의 문항 수를 함께 보여 준다. 전체가 100개(5페이지)를 넘으면 사용자가 범위를 고를 때까지 ID 목록과 보기 링크로 넘어가지 않고 여기서 답을 마친다. 요청의 "전부"는 범위를 고른 것이 아니다.
7. **ID 목록.** 좁힌 범위의 최종 필터로 `limit: 20` 새 검색을 시작해 `nextCursor` 로 페이지를 넘기며 ID 를 모은다(앞의 `limit: 1` 집계 검색을 이어 쓰지 않는다). 기본 5페이지(100개)까지 받고, 더 필요하면 이어 받을지 묻는다. 사용자가 원하면 25페이지(500개)까지 받을 수 있다. 대화가 길어지므로 Claude Code 에서는 이 수집을 `question-scout` 에 맡긴다.
8. **이미지.** 보기 링크는 한 번에 10개씩, 처음에는 한 묶음만 만들고 더 필요하면 묻는다. 모아 둔 ID 에서 「문제은행 구독 필요」·「문제은행에서 빠진 문항」·권한 없음·사용 불가 ID 는 빼고, 남은 ID 를 `cell_image_link` 에 10개씩 나눠 보기 링크를 만든다. 여러 문항을 한꺼번에 `cell_image` 로 판독하지 않는다.

## 결과

- 규모·분포 표 아래에 `「수학비서 데이터」` 문구를 그대로 쓰고 `cell_search.totalCount` 와 그때 쓴 필터(단원 ID·난이도·범위)를 적는다.
- 받은 ID 수(쓸 수 있음 N / 열 수 없음 M, 사유별)와 전체 수를 함께 적는다(예: 100(쓸 수 있음 96 / 문제은행 구독 필요 4) / 3,598).
- "일괄 내보내기는 MCP 에서 지원하지 않는다"를 분명히 쓴다.
