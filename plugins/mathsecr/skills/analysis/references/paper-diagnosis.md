# 문제지 진단

## 입력

`paperId` 또는 제목, 요청 단원 범위, 교육과정(미상 가능), 위임 전 이미지 사용량·잔액·상한. 학생 성적이 아닌 **문항 배점**만 다룬다.

## 호출 순서와 상한

1. ID가 없으면 `mypaper_list(searchMode: "title", keyword, limit: 10)` 1페이지. 여러 후보면 선택지를 반환하고 멈춘다. `mypaper_detail(paperId)` 1회. `progress: editing`이면 문항을 읽지 말고 상세만으로 제한 보고한다.
2. 교육과정 미상이면 `curriculum_list` 1회. 요청/기본 ID로 `mypaper_cells(paperId, curriculumId, isNumberSorted: true, limit: 20)`를 시작한다. **응답의 저장된 `curriculumId`를 이후 조회 기준**으로 삼고 요청과 다르면 알린다. 커서 중에는 최초 필터를 유지하고, 저장 ID로 필터를 바꿔야 한다면 커서를 버리고 처음부터 읽되 총 10페이지를 넘기지 않는다. 번호별 발생을 보존하며 중복 페이지는 제거한다. 저장 ID가 없으면 교육과정을 추측하지 않는다. 문항이 오지 않고 `lockedProblemBankCount` 가 1 이상이거나 그 필드가 없거나 null 이면 문제은행 문항이 잠겨(또는 구독을 확인하지 못해) 문항이 오지 않은 것이다 — 빈 문제지가 아니다. 응답 `curriculumId` 는 요청값을 되돌려 준 것이라 저장값으로 보지 않는다. 3·5·6·7단계를 멈추고, 문항 수·난이도 분포는 `mypaper_detail` 로, 배점은 4단계 `mypaper_scores` 로만 제한 보고한다. 0문항 진단을 내지 않는다. 확인은 수학비서 웹에서 하도록 안내한다(구독을 권하지 않는다).
3. 저장 교육과정으로 `chapter_tree(curriculumId, keyword, depth: 4)` 최대 2회(잘림 시 범위를 좁힌 1회 포함). 요청 범위가 없으면 조회된 트리 범위라고 명시한다. `tree_id`와 `chapter_id`를 구분해 문항의 단원 경로와 대조한다. 불명확한 매핑은 미확인으로 둔다. 문항 단원(`cell_detail.chapters[].id`)이 4단계 트리에 없으면, depth 4 결과에서 그 단원의 부모(4단계) 제목을 `keyword`로 `depth: 5`를 1회 더 부른다(넓은 keyword 는 다른 갈래가 40개 상한을 먼저 채울 수 있다). `isAlias: true` 단원은 별칭이므로 `cell_search`의 `chapterTreeIds`에는 `originTreeId`를 쓴다.
4. `mypaper_scores(paperId)` 1회. `questionNumber`와 문항 번호를 대조한다. 번호가 중복/누락되면 순서로 억지 결합하지 않는다. 같은 `cellId`가 두 번호에 있으면(같은 문제 처리 뒤 번호를 지키려고 남긴 것일 수 있음) 오류가 아니라 사실로 적고, 분포 집계에서는 번호별로 센다. `null`은 미설정, 0은 설정된 0점이다.
5. 메타데이터로 단원별 문항 수·미포함 단원, `answerMetadata.difficulty.mathSecr` 분포, `answerMetadata.type` 균형, 같은 난이도 내 배점 편차를 집계한다. 회원 난이도(`member`)는 별도 열, 혼합하지 않는다. 여러 답 유형/난이도가 있으면 복수·미상으로 세고 분모를 밝힌다. 단원 중복 집계도 밝힌다. 배점 편차는 오류 확정이 아닌 Claude 확인 제안이다. 출제 완료 문제지의 쓸 수 있음 개수는 「출제본 기준」으로 적고, 지금 상태는 문제지 점검(`mypaper`)에서 확인한다고 적는다.
6. 같은 단원·난이도에 몰린 대표 문항 최대 3개에 `similar_cells(cellId, curriculumId, relationType: "5depth", limit: 10)` 각 1페이지. **`currentPaperId`는 넣지 않는다**(그 문제지에 든 문항이 결과에서 빠져 내부 유사 관계가 0건이 된다). `appliedRelationType`과 양끝 ID가 확인된 관계만 문제지 내부 간선으로 묶는다. `PC`/`NC` 등 다른 관계를 검사하지 않았다면 판정하지 않는다. 관계의 추이성·같은 단원만으로 동일 문항임을 주장하지 않는다. 유사 문항은 열 수 있는 문항만 오므로 권한 확인용 `cell_detail` 은 부르지 않는다(TX 결과는 최대 5분 캐시지만 관계 판정만 할 때는 확인하지 않는다). 미검사 쌍은 유사성 미확인이다.
7. 위 집계에서 발견한 배점·난이도 이상치 등 **최대 2문항**만 필요시 `cell_image(cellId, curriculumId, paperId, parts: ["question"])`로 문제지에 실린 출제본을 확인한다. 풀이 부담 판단이 꼭 필요하면 허용된 `explanation` 부분을 선택한다. 전체 문항 이미지는 읽지 않는다. `not_in_paper`·`paper_locked`·`paper_unverified` 로 거절되면 다시 부르지 않고 사유와 「출제본 미확인」을 적는다(잠긴 문제지는 수학비서 웹에서 확인하도록 안내). `paperId` 가 "입력 형식" 오류로 거절되면(예전 도구 정의·서버) 되풀이하지 않는다. `paperId` 없이 다시 부르는 것은 지금 상태 `cell_detail` 이 그 문항을 지금 열 수 있다고 보였을 때(사용 불가·권한 없음·문제은행 구독 필요가 아님)만이고, 그때 「지금 상태 이미지(출제본 아님)」로 적는다. 지금 열 수 없거나 확인하지 않았으면 이미지 없이 「출제본 이미지 미확인」으로 둔다. 대체 후보·유사 문항 이미지에는 `paperId` 를 넣지 않는다.

## 이미지 예산과 중단

회원 공용 일 300장, 요청 누적 기본 4장. 위임 전 사용량 차감, 순차 호출. 호출 전 여유는 이번 호출이 돌려줄 수 있는 최대 장수로 계산한다(question 1장, 지문이 있으면 +1, 해설은 지정한 해설 ID 수, 기본 1장), `returned` 장수로 정산한다. 필요한 2문항 비교는 이유를 밝히고 8장까지, **8장 초과 전 사용자 확인**. `budgetRemainingToday`가 이번 호출 예상 장수보다 작으면 멈춘다. 이미지 호출은 병렬로 하지 않는다(동시 호출 중에는 다른 호출의 예약분이 잔액에서 잠시 빠져 보인다). 잔액은 가장 최근 응답의 `budgetRemainingToday`를 쓰고, 도구 오류로 잔액이 오지 않으면 직전 잔액에서 요청 장수를 뺀 값으로 이어 간다. 직전 잔액이 없으면 멈춘다. 실패한 부분은 차감되지 않으며 `denied`에 사유가 온다(해설은 `explanationId` 포함; `not_found` = 그 문항의 해설 ID가 아님, `no_explanation` = 해설이 없는 문항, `permission_denied` = 권한 없음). 응답에 `fallback: "cell_image_link"`가 있으면 읽지 못한 그 부분은 사용자에게 보기 링크를 제안한다. `denied`의 ID·부분·사유를 보고하고 자동 재시도하지 않는다. "이미지를 가져올 수 없습니다" 오류는 링크 보기를 제안하고 수학비서 데이터만으로 계속한다. 최종 분석자가 직접 판독하며 전달 판독은 판독자·출처와 재판독하지 않았음을 남긴다. 해설의 정답은 요청 없이 공개하지 않고 문항·풀이·LaTeX 전사는 하지 않는다.

`hasMore`가 10페이지 뒤에도 남거나 `nestedTruncated`가 복구되지 않으면 **조회된 일부 기준**, 전체 누락·중복 없음 보장 금지. 커서로 내부 잘림을 복구했다고 간주하지 않는다. 권한 없음·사용 불가는 이미지와 내용 평가에서 제외한다. 입력/output schema 오류·인증 오류는 반복하지 말고 `/mathsecr:status` 재연결 안내. 학생 정보·쓰기·구매·브라우저 자동화 금지.

## 출력

요약 두 문장 뒤 다음 표, 읽은 범위/분모·잘림·미확인·이미지 누적 장수/잔액을 덧붙인다.

| 점검 항목 | 집계/문항 ID·번호 | 확인 제안 | 근거 |
|---|---|---|---|
| 단원·난이도·답 유형·배점·유사 묶음 | 값과 분모 | Claude 제안 또는 확인 불가 | 「수학비서 데이터」 도구.필드 + paperId/cellId/tree_id |
| 이상치 내용 | 판독한 ID | 조건·계산 부담에 대한 해석 | 「이미지 판독(Claude 해석)」 cellId + part + 판독자 |

모든 집계·제안은 위 근거를 붙이며 Claude 평가를 저장된 평가라고 쓰지 않는다. 태그를 언급하면 사전/검색 필터 근거만 쓰고 「문항별 부착 태그 확인 불가」라고 표시한다. 수정은 수학비서 웹에서 진행하도록 안내한다.
