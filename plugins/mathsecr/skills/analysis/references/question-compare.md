# 두 문항 비교

## 입력

문항 ID 2개, 교육과정, 비교 목적(조건·계산 부담·대체 가능성), 이미지 사용량·잔액·상한. ID/교육과정이 불명확하면 선택지를 제시하고 멈춘다.

## 호출 순서와 상한

1. 필요시 `curriculum_list` 1회. 두 문항에 `cell_detail(cellId, curriculumId)` 각 1회로 단원·`answerMetadata`·권한을 읽는다. `hasPermission`이 true가 아니거나 `isUnavailable`/`isProblemBankRemoved`가 true면 그 문항의 판독·활용을 멈춘다.
2. `similar_search_setting` 1회. 한 기준 문항에 `similar_cells(cellId, curriculumId, relationType, limit: 10)`를 `PC`(같은문제), `NC`(숫자변형), `5depth`(유사문제), `4depth`(같은유형), `MT`(다른단원 유사문제) 순으로 각 1페이지, **합계 최대 5회** 호출한다. 비교 상대가 나온 관계와 `appliedRelationType`을 기록한다. 관계 하나를 찾았더라도 사용자가 요청한 나머지 관계는 확인한다. `TX`면 텍스트 유사성으로 보고 나머지 관계 호출 중단. 결과 미등장이나 잘림은 관계 없음의 증거가 아니다. 유사 결과에는 권한 필드가 없으므로 이미 읽은 상대의 `cell_detail`로 확인하며, 새 후보로 비교 범위를 넓히지 않는다.
3. 단원 경로 해석이 필요하면 `chapter_tree(curriculumId, keyword, depth: 4)` 1회. 태그 질문이 있으면 `cell_tag_search(keywords, limit: 10)` 1페이지로 **태그 사전**만 확인한다. 필터 결과가 필요하면 `cell_search(curriculumId, adaptiveTagIds, limit: 10)` 1페이지. 검색에 포함됐다는 사실만 쓰고 부착 태그라고 추정하지 않는다. 항상 **「문항별 부착 태그 확인 불가」**를 표시한다.
4. 메타데이터 비교만으로 충분하면 종료. 조건 차이와 계산 부담을 설명해야 하면 두 문항에 `cell_image(cellId, curriculumId, parts: ["question"])`를 순차 호출한다. 지문도 실제 반환된 경우에만 판독한다. 풀이가 꼭 필요하면 `parts: ["explanation"]`을 예산 안에서 선택한다. 별도 `passage` 입력이나 추측한 `explanationIds`를 보내지 않는다.

## 이미지 예산과 중단

회원 공용 일 300장, 요청 누적 기본 4장, 위임 전 사용량 차감. 호출 전 여유는 이번 호출이 돌려줄 수 있는 최대 장수로 계산한다(question 1장, 지문이 있으면 +1, 해설은 지정한 해설 ID 수, 기본 1장). `returned` 실제 장수를 누적하고 순차 호출만 한다. 두 문항 확인에 필요하면 이유를 알리고 8장 이내로 확대, **8장 초과는 사용자에게 묻고 대기**. `budgetRemainingToday`가 이번 호출 예상 장수보다 작으면 멈춘다. 이미지 호출은 병렬로 하지 않는다(동시 호출 중에는 다른 호출의 예약분이 잔액에서 잠시 빠져 보인다). 잔액은 가장 최근 응답의 `budgetRemainingToday`를 쓰고, 도구 오류로 잔액이 오지 않으면 직전 잔액에서 요청 장수를 뺀 값으로 이어 간다. 직전 잔액이 없으면 멈춘다. 실패한 부분은 차감되지 않으며 `denied`에 사유가 온다. 응답에 `fallback: "cell_image_link"`가 있으면 읽지 못한 그 부분은 사용자에게 보기 링크를 제안한다. `denied`의 ID·부분·사유를 보고하고 자동 재시도 금지. "이미지를 가져올 수 없습니다" 오류에는 `cell_image_link` 보기를 제안하고 **수학비서 데이터만으로 비교 계속**, 내용 차이는 미확인으로 둔다. 최종 분석자가 이미지를 가져오며 전달받은 판독은 판독자·출처와 재판독 안 함을 명시한다. 해설에는 정답·전체 풀이가 있으므로 요청 없는 정답 공개, 문항·풀이·LaTeX 전사를 금한다.

관계 5회·검색 1페이지·이미지 한도에 도달하면 추가 탐색을 멈추고 범위 한계를 쓴다. 인증·입력/output schema 오류는 재호출하지 말고 `/mathsecr:status` 안내. 학생 정보·쓰기·구매·브라우저 자동화 금지.

## 출력

| 비교 항목 | 문항 A (ID) | 문항 B (ID) | 차이와 근거 |
|---|---|---|---|
| 단원·난이도·정답 유형 | 저장값 | 저장값 | 「수학비서 데이터」 cell_detail.필드 + 각 cellId |
| 관계 | 요청 관계 | 실제 적용 관계/검색 범위 | 「수학비서 데이터」 similar_cells.appliedRelationType/cells + 양끝 ID |
| 태그 사전·필터 | 확인 범위 | 확인 범위 | 「문항별 부착 태그 확인 불가」 + 도구.필드/태그 ID |
| 조건·계산 부담 | 판독 요약 또는 미확인 | 판독 요약 또는 미확인 | 「이미지 판독(Claude 해석)」 cellId + part + 판독자 |

권장은 **Claude 제안**이라고 쓰고 위 근거 라벨을 함께 붙인다. 난이도와 예상 소요 시간/계산량은 같다고 가정하지 않는다. 마지막에 미확인 사항·누적 이미지 장수/잔액, 실제 교체는 수학비서 웹에서 한다고 적는다.
